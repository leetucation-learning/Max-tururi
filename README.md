## Publicare pe GitHub Pages

1. Creează un depozit nou (de exemplu `Vanatoarea-de-indicii`) în contul `leetucation-learning`.
2. Încarcă **tot conținutul** acestei arhive în rădăcina depozitului (inclusiv fișierul `.nojekyll`).
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
4. După 1–2 minute, cursul este la `https://leetucation-learning.github.io/<nume-depozit>/`.

În afara unei platforme LMS, progresul și fișa de lucru se salvează în browserul elevului (localStorage).
